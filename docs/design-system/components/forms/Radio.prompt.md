Pilihan tunggal. `Radio` untuk daftar ringkas; `RadioCard` untuk pilihan yang butuh penjelasan atau nominal (metode pembayaran, paket termin escrow).

```jsx
<Radio name="peran" label="Saya mahasiswa" description="Mencari proyek dan membangun portofolio" checked />
<RadioCard name="termin" label="Bayar sekaligus" price="Rp 2.500.000"
  description="Seluruh dana ditahan di escrow saat kontrak dimulai." checked />
```
